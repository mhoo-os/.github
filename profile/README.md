# Mhoo

**Business data, connected tools, and AI-assisted work—in one workspace.**

We're building business applications on [Twenty](https://github.com/twentyhq/twenty), with a focus on connected records, useful workflows, and analysis you can trace back to its sources.

Our current work explores financial investigation, provider integrations, and tools that help people and AI agents work with the same business information.

## Explore the work

- [Twenty foundation](https://github.com/mhoo-os/mhoo-twenty-next) — our current clean-foundation development repository, based on upstream Twenty.
- [Finance investigation prototype](https://github.com/mhoo-os/finance-investigation-workspace) — a synthetic-data prototype for evidence-first financial analysis.
- [Dark Factory](https://github.com/mhoo-os/dark-factory) — tooling for bounded, issue-driven software development.

## Built with existing foundations

We build on open-source projects rather than replacing what already works. Twenty provides the foundation for workspace records, permissions, APIs, and application development. Each repository documents its upstream sources and licensing.

## Development status

Mhoo is under active development. Some repositories are prototypes or retained historical work, not supported production releases. Check the relevant repository's documentation and issues before using it.

For questions about a public project, use its issue tracker where available. Please do not post credentials, customer records, or other private information in public issues.
